# Phase 8 bounded operating envelope

These cases and limits were selected before the Phase 8 measurements. Passing checks qualify the listed operation and observed environment. They do not make every size-duration combination equally practical, turn correctly reported inadequate designs into adequate designs, or validate physical equipment.

The largest browser case is a compiled-worker protocol compatibility check with a 60-second test deadline and no retries; it is independent of the historical Firefox-only 500,000-accelerator Step 10s test. Chromium and WebKit exclusions of that exact old Step 10s position remain explicitly recorded. A successful one-second case is not claimed as proof of an excluded ten-second UI journey.

The script `node scripts/phase-8-measure.mjs --out=/absolute/new/evidence-directory` runs the existing Phase 1 measurement script and the two added cases serially. Each subprocess has a predeclared 180-second ceiling; timeout/native nonzero exit fails the run and retains its log. Results include source commit/tree/lock digest, configuration and disturbances, all three samples, separate solver-operation and end-to-end times, process memory snapshots, process RSS high-water observations, full metrics/controller transitions/recovery, checkpoint hashes and exact replay outcomes. Only `solverMs`, an execution timing observation, is normalized during physical checkpoint comparison.

Run this measurement command only after other CPU-heavy tests have stopped. Record material host contention in the external execution receipt. Browser/version/OS and native worker results are retained in Playwright's JSON report and attachments. Node `heapUsed` is not process RSS. Process-lifetime maximum RSS includes module loading and all case operations; before/after heap observations are not peak heap measurements. Unknown browser memory counters are unavailable, never zero. These are single-machine observations with finite samples, not universal guarantees.

Existing worker restrictions remain unchanged: 8,000 module work units per chunk, at most 10 s per chunk, 2,000,000 per job and 120,000 ms soft job wall deadline. An indivisible oversized event boundary is resource-limited and retains inspectable prior source; normal job budget exhaustion retains the last complete checkpoint. Limits are execution boundaries, distinct from invalid input and valid-but-inadequate design results. Structural 6,250-module capacity is an allocation guard, not an enabled canonical campus claim.

Native measurements and candidate verdicts live outside the frozen source tree in the release evidence package. The final receipt supplies measured values and current verdict; this document declares the reproducible cases and interpretation without creating a self-referential acceptance commit.
