3. Fetch main and Pages again, preserve any newer work, and recheck current production plus `v2-preview/`. Scan outgoing files for secrets, recordings, private telemetry and unintended contents.

If hosted correctness/artifact verification fails, preserve evidence, check for concurrent new releases, restore the freshly captured rollback as a normal successor on Pages, observe deployment, and verify restoration.
